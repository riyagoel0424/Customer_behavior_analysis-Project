# Customer Behavior Analysis Dashboard

## Overview

This project analyzes customer purchasing behavior using SQL and Power BI to uncover valuable business insights. The dashboard provides a comprehensive view of customer spending patterns, product category performance, subscription trends, and customer reviews.

## Objectives

- Analyze customer purchasing behavior
- Identify top-performing product categories
- Evaluate subscription trends among customers
- Track revenue and sales performance
- Build an interactive dashboard for business decision-making

## Tools & Technologies

- SQL (PostgreSQL)
- Power BI
- Excel / CSV
- Data Cleaning & Transformation

## Dashboard Features

### KPI Cards
- Total Customers
- Average Purchase Amount
- Average Review Rating

### Visualizations
- Revenue by Category
- Sales by Category
- Subscription Status Analysis
- Revenue by Age Group
- Sales by Age Group

### Interactive Filters
- Subscription Status
- Gender
- Category
- Shipping Type

## Key Business Insights

- Clothing category generated the highest revenue among all categories.
- Majority of customers do not have an active subscription.
- Young Adult customers contributed the highest sales volume.
- Accessories emerged as the second-highest revenue-generating category.
- Customer purchasing behavior varies across different age groups.

## Dataset Information

The dataset contains customer purchasing information including:

- Customer ID
- Age Group
- Gender
- Category
- Purchase Amount
- Review Rating
- Subscription Status
- Shipping Type
- Previous Purchases
- Frequency of Purchases
